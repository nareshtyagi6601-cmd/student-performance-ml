# Student Performance Prediction System

B.Tech CSE / AI-ML 1st Year Mini Project

## Objective
Predict a student's expected final marks using study hours, attendance,
previous marks, assignment score and practice hours.

## Machine Learning
- Type: Supervised Learning
- Algorithm: Decision Tree Regression
- Language: Python

## How to Run

1. Install Python 3.10 or newer.
2. Open Command Prompt/Terminal in this project folder.
3. Install dependencies:

   pip install -r requirements.txt

4. Run:

   python app.py

## Project Files
- app.py - Main ML application with GUI
- student_data.csv - Sample dataset
- requirements.txt - Required Python libraries
- project_report.txt - Short project report
- viva_questions.txt - Viva questions and answers

## Note
This is an educational mini-project using a sample dataset. The predictions
are for demonstration and learning purposes.
