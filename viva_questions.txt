VIVA QUESTIONS AND ANSWERS

1. What is Machine Learning?
Machine Learning is a branch of AI in which computers learn patterns from data
and use them to make predictions or decisions.

2. Which type of ML is used?
Supervised learning.

3. Which algorithm is used?
Decision Tree Regression.

4. Why is regression used?
Because the target, final marks, is a numerical value.

5. What is a feature?
A feature is an input variable used by the model for prediction.

6. What is the target?
The target is the value the model tries to predict. Here it is final marks.

7. What is train-test split?
It divides data into training data for learning and test data for evaluation.

8. What is MAE?
Mean Absolute Error measures the average absolute difference between predicted
and actual values.

9. What is R-squared?
R² indicates how well the model explains variation in the target values.

10. What is overfitting?
Overfitting occurs when a model learns the training data too closely and
performs poorly on unseen data.
